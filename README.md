# 諸葛亮 上疏 — 제갈량 상소문

촉한의 승상 제갈량이 날마다 올리는 상소문. 궁궐에서 「오늘의 한마디」를 내리고,
두루마리에 제1장(클로드코드를 쓰는 법)과 제2장(생업과 삶의 방향)을 적어 올린다.
공백 제외 5,000자 이상.

**상소창 주소 — 집에서도 사무실에서도 같은 주소**

<https://claude.ai/artifact/MYg7G3jhfjFVxSLrqYu83n>

## 왜 이렇게 만들었나

앞서 만든 것은 사무실 PC 안에서만 도는 물건이었다. 파일도 작업 스케줄러도 그 PC에만 있으니
집에서는 열릴 수가 없었다. 그래서 상소문 자체를 웹으로 옮겼다.

- **상소문은 한 곳에** — claude.ai에 올린 위 주소 하나뿐이다. 어느 컴퓨터, 어느 폰에서 열어도 같다.
- **그날의 상소는 하루에 한 번만 지어진다** — 아침에 사무실에서 먼저 열면 그날 상소가 지어져 서고에 갈무리되고,
  저녁에 집에서 열면 지어 둔 그 상소가 그대로 펴진다. 두 번 짓지 않는다.
- **승상의 기록도 한 곳에** — 「승상께 아뢰어 기록을 고치다」로 고치면 두 PC 모두에 반영된다.

## 집·사무실 양쪽 PC 설정 (각각 한 번씩)

### 1) 매일 오전 9시에 저절로 뜨게 하기

`windows` 폴더를 두 PC에 각각 내려받아 두고, PC마다 한 번씩 실행한다. 관리자 권한은 필요 없다.

```powershell
powershell -ExecutionPolicy Bypass -File "설치.ps1"
```

등록되는 것:

| 트리거 | 동작 |
|---|---|
| 매일 09:00 | 기본 브라우저로 상소창을 연다 |
| 로그온 1분 뒤 | 9시에 PC가 꺼져 있었으면 켜자마자 연다 |

두 트리거가 겹쳐도 하루에 한 번만 뜬다(`%LOCALAPPDATA%\ZhugeSangso\last-open.txt` 로 그날 열었는지 본다).

지금 당장 한 번 열어 보려면:

```powershell
powershell -ExecutionPolicy Bypass -File "열기.ps1" -Force
```

그만두려면 `제거.ps1`을 실행한다. 상소창 자체는 그대로 남는다.

### 2) 브라우저를 켤 때마다 뜨게 하기 (스크립트 없이)

크롬 → 설정 → **시작 그룹** → 「특정 페이지 또는 페이지 모음 열기」 → 위 주소를 추가.
설치 스크립트 대신 이 방법만 써도 된다.

### 3) 사이드바에 고정

claude.ai 왼쪽 사이드바에 꽂아 두면 폰에서도 한 번에 열린다.

## 승상은 무엇을 읽고 상소를 짓는가

`승상의 記錄`(페이지 안에서 고칠 수 있다)에 적힌 것만 읽는다. 처음에는 아래가 들어 있다.

- 1971년생, 소방 현장지휘팀장, 2031년 퇴직 예정
- 실제 업무 — 화재방어 검토회의 자료, 소방시설 3D 시각화, 한글 공문, 엑셀 서식
- 엑셀 서식 규칙(수동입력 셀 노란색, 바깥선 중간 실선·안쪽 점선, 행높이 20, 금액 원 단위 우측정렬, VLOOKUP 우선)
- 클로드코드를 2025년 9월에 처음 잡은 초심자라는 점

새로 알리고 싶은 것이 생기면 「승상께 아뢰어 기록을 고치다」에 한 줄 더 적으면 된다.

**지키는 금도** — 재산·투자·세금은 원칙과 태도만 말하고 특정 종목·시기·절세 방법은 말하지 않는다.
의학적 진단이나 처방도 하지 않는다. 구체적인 판단은 그 일을 업으로 하는 사람에게 묻도록 권한다.

## 파일

```
web/index.html   상소창 — 궁궐 장면(SVG), 두루마리, 서고, 승상의 기록
web/sangso.js    원전(原典) 상소 — 제1장 3편·제2장 3편·한마디 14수
windows/설치.ps1  이 PC에 매일 9시 자동 열기를 등록
windows/열기.ps1  상소창을 연다 (하루 한 번)
windows/제거.ps1  자동 열기 등록을 지운다
```

`web/index.html`은 claude.ai에 올린 상소창의 원본인 동시에, 그대로 두 배포처에서 돈다.

- **claude.ai 위에서** — 승상이 그날의 상소를 새로 짓고, 서고(db)에 갈무리한다.
- **파일을 직접 열거나 웹서버에 올렸을 때** — 인터넷이나 클로드가 닿지 않아도
  `sangso.js`의 원전 상소가 날짜에 따라 아홉 가지로 돌아가며 펴진다. 화면은 똑같다.
