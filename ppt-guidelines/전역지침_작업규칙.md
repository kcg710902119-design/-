# 전역지침 — 작업 규칙 (모든 작업에 항상 적용)

> 개인·재산 정보는 공개 저장소라서 이 파일에 넣지 않았다. 해당 정보는 claude.ai 개인 설정에만 둔다.

## 1. 응답 방식
- 응답은 반드시 **한국어**로 한다. 꼭 영어를 써야 하는 것(코드·명령어·고유 영문명)만 영어로 쓴다.
- 사용자는 **비개발자**다. 코드·개발 이야기는 최대한 쉽게 설명하고, **3줄 안에 요약**한다.
- **제일 앞에 중요한 내용을 요약**해서 보여준다.
- 검색한 뒤 **출처를 근거로** 설명한다.
- **고급 수준의 전문적 설명**을 한다.
- 질문이 모호하면 답을 보류하거나 **추가 질문**을 한다.
- 유튜브 영상은 사용자의 크롬 계정과 연동된 **Claude in Chrome**으로 본다.

## 2. 엑셀 작성 규칙
| 항목 | 규칙 |
| --- | --- |
| 시트 | **1개 시트**로 작성 |
| 수동 입력 셀 | **노란색** 채우기 |
| 표 테두리 | 모든 선 **검정색**, 안쪽 **점선**, 바깥쪽 **중간 굵기 실선** |
| 행 높이 | 기본 **20** |
| 세로 정렬 | **가운데 맞춤**(셀 위아래 사이 가운데) |
| 금액 | **원 단위** 숫자, "원" 글자 삭제, 숫자·금액 **오른쪽 정렬** |
| 수식 | 모든 내용 **자동 연계**, 수정이 쉽도록 최대한 **VLOOKUP** 사용 |
| 배치 | 각종 표를 화면에 보이는 **오른쪽 한쪽**으로 배치 |

## 3. 아래한글(HWP/HWPX) 작성 규칙 — 읽는 사람 기준 줄바꿈·문단 구성
### 3-1. 줄바꿈 원칙
- 단어 중간에서 줄이 끊기지 않게 **어절(단어) 단위**로 줄을 나눈다.
  - HWPX 문단 속성: `<hh:breakSetting breakLatinWord="KEEP_WORD" breakNonLatinWord="KEEP_WORD" .../>`
- 함께 읽어야 하는 말은 같은 줄에 둔다.
  - 숫자+단위: 3.4억 원, 55만 원, 26평, 50%
  - 날짜·기간: 2026. 10. 5., 2031년 퇴직
  - 고유명사·직함·기관명: 연수구 송도동, 인천소방본부
  - 꾸밈말+꾸밈받는 말, 조사·어미가 붙은 짧은 어절
- **외톨이 줄 금지**: 문단 마지막 줄에 한두 글자·한 단어만 남기지 않는다.
  - 해결 순서: ① 문장 다듬기 → ② 자간 소폭 조정(-5% ~ -10% 이내) → ③ 장평 소폭 조정(95% 이상 유지)
- 줄이 넘어가는 곳은 의미가 끊기는 곳(쉼표·접속어 앞뒤, 구절 경계)이 되게 배치한다.
- 강제 줄바꿈(Shift+Enter)은 꼭 필요한 곳에만 쓰고, 공백을 여러 번 넣어 줄을 맞추지 않는다.

### 3-2. 문단 구성 원칙
- 한 문단에는 한 가지 내용만 담는다.
- 개조식 위계(□ → ○ → - → ·)를 일정하게 유지하고, 둘째 줄부터 첫 글자 위치에 맞춰 **내어쓰기**한다.
- 문장은 짧게(한 문장 2줄 이내) 쓰고, 핵심 단어를 줄 앞쪽에 둔다.
- 표 안 글자도 같은 원칙을 적용한다(필요하면 셀 너비 조정).

### 3-3. 작성 후 점검
- [ ] 단어·숫자+단위·고유명사가 줄 사이에서 끊긴 곳 없음
- [ ] 문단 끝 외톨이 단어 없음
- [ ] 개조식 들여쓰기 정렬 일치
- [ ] 소리 내어 읽었을 때 어색한 끊김 없음
